# DreamGlass 3.0.3 · For ColorOS 17

- 【安全区域】在 **DreamGlass → 设置 → 安全区域** 分别编辑桌面和锁屏。可以在对应壁纸上圈画多个区域，支持撤销、清空；圈内跳过玻璃扭曲，保留模糊和高光。
- 【锁屏时钟】安全区域也约束部分主题绕过普通材质路径的原生时钟效果；圈外沿用原有合成。
- 【壁纸预览】已有授权时优先通过 Root 读取对应壁纸；入口内提供 **申请 Root 权限** 按钮，系统不能提供预览时也可以手动选图。Magisk 31.1 需先在其「超级用户」页面授权 DreamGlass。

版本号：3.0.3（3000005）。沿用此前正式版签名，可以覆盖升级并保留配置。安装后按需要重新加载 LSPosed 的桌面或 SystemUI 作用域；应用不会自动重启这些进程。

正式 APK、Release 单元测试、Lint 和升级签名已校验。未在 ColorOS 实体设备上验证本版本的时钟与壁纸效果。详见[验证记录](validation/3.0.3/README.md)。
