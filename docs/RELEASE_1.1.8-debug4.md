# DreamGlass 1.1.8-debug4 · COS17 定向修复候选

本版继续修复用户在 debug3 上确认的回归，作为预发布候选，不替代最新正式版 1.1.7。**此候选按用户最新要求未再连接 ADB；没有安装、重启或进行真机视觉验收。**

- **计算器**：保留以背景 SVG 绘制的运算符及原生数字；只替换已验证的独立填充、阴影。父容器通过正常背景 setter 更新透明度元数据，避免跳过绘制后仍留下黑色方块；材质范围使用实际子按钮及其局部变换，避免按整个网格单元绘制。
- **相册**：确认原生材质宿主为 BlurButtonWrapperView，按宿主的真实矩形和圆角统一渲染；接管独立 COUI 模糊／描边及绘制尾部高光，避免重复轮廓。图标与子视图保持原生，关闭、脱离窗口或异常时归还原生材质请求。
- **负一屏**：不再将高光 Overlay 当成卡片底色；适配三种实际卡片填充宿主（第四种图片宿主仅保留绘制作用域隔离，不给头像和内容图片挂材质）。按原生 Path 范围和背景 alpha 挂载同一 GPU 材质，保留内容、圆角遮罩和输入。
- **窗口倾斜方向**：标准与轻窗口动画均读取本次启动／退出对应的真实图标端点，以同一目标的原生矩阵叠加倾转，保留缩放、中心轨迹和动画端点；缺少可信端点时保持原生，不沿用固定方向或上个应用的位置。这仍是平行投影兼容模式，不能等同完整透视。
- **材质几何**：背景采样、形状偏移及二级裁剪统一使用宿主局部矩形；位置、按压缩放或背景透明度变化时及时更新，不再复用 250ms 前的几何。

208 项 JVM 回归通过；Debug／Release 构建通过，Lint 无 Error／Fatal。新增加了计算器前景、非零原点材质几何和 OEM 背景通道的调试探针，**本轮未执行 GPU 回读或厂商应用测试**。编译、静态 APK 合约和单元测试不能证明实际 OEM 合成效果。

已保留旧、新 Launcher 的独立合约和此前的渲染区域调试开关。没有重新启用全局 View.drawBackground 抑制、前景整体模糊、CPU 模糊、全局窗口事务修改或延迟复位。此前已认可的智能侧边栏材质路径保持。

debug3 APK 发布暂停，保留源码标签及本地备份用于追溯，不作为推荐下载。新包只有重新加载对应应用／桌面作用域后才会执行新 Hook；本版不自动进行安装或重启。
