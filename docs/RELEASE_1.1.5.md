# DreamGlass 1.1.5 · For ColorOS 17

- 默认恢复 1.0.7 的经典宽幅折射；材质工作室预览上方新增“新版渲染方案”，可一键切换紧凑镜片，保留现有参数和 IOS风预设。
- 修正音乐控制卡片的玻璃几何：局部裁剪不再缩小圆角形状，滚动偏移不再作为扩张留白，原生播放控件布局与点击区域保持原样。
- 统一自定义背景模糊覆盖匹配的通知长按、图标菜单及负一屏路径，补齐 0% 时桌面图标的残余模糊处理。
- 增强 COS17 窗口逐目标透视、原生矩阵布局与最终事务合成；通知倾斜跟随原生进度，在可见动画中段达到峰值。倾斜继续列为实验功能。
- 补充主题时钟绘制出口及相机按钮材质兼容。保留通知／多任务 GPU 粒子和已确认的侧边栏材质。

148 项单元测试、6 组 GPU／生命周期回归、Debug／Release 构建通过；Lint 0 Error、303 Warning。两种光学曲线分别与 1.0.7／1.1.4 的 48 组 GPU 对照最大通道差为 0；媒体裁剪 6 组预乘通道差不超过 1/255。正式 APK 沿用原升级签名，已用普通 ADB 覆盖安装并核对手机上文件哈希，配置保留。

音乐修正及倾斜的最终真机外观尚未在重启宿主后验收，主题时钟仍可能偏平；没有进行新版本耗电与长期稳定性测量。独立音量窗继续使用系统原生材质。应用内主界面的模式开关在未连接框架时只更改预览，并明确提示未保存。

升级后按自己的方式重新加载 SystemUI 和桌面，再检查系统效果。源码、APK、含许可的完整发行包和 SHA-256 校验均随本次发行提供，正式 APK 不包含 debug 探针或参考着色器资产。
