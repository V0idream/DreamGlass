# 3.0.2-debug1：图标渲染计算复用

本次在 3.0.1 实时图标绘制链路上减少无效工作，不改变实时壁纸坐标更新策略，不增加抓屏、定时器或空闲轮询。

## 优化范围

- 图标模糊为零时，原有模糊准备函数已经直接返回；现在缓存中的清晰壁纸也可直接复用，省去重复排队和缩放复制。需要实际栅格化 RenderNode 时不再创建半径 0.01 的模糊效果。
- 每个材质保存已上传的着色参数。未变化的参数不再重复分配数组或调用原生 uniform 写入；图标移动、透明度变化以及材质重建仍会更新所需参数。
- 缓存相同壁纸尺寸、屏幕尺寸、偏移和缩放对应的投影变换。每个图标仍使用当前屏幕坐标采样；像素着色器中的前景和壁纸缩放比例改为预先计算。
- 折射为零时跳过光线弯折计算；浮雕和精细图案跳过最终会被覆盖的通用前景背景采样。完全透明的图标跳过绘制准备。
- 自定义导入图片不请求其绘制路径用不到的壁纸；已缓存的图片绑定不重复准备坐标矩阵。
- 复用相同半径的 RenderEffect、相同图案状态的材质参数，以及各 ItemInfo 类型的反射访问器。只缓存访问器，不缓存组件、用户或快捷方式的实际值，保证重新绑定后读取新值。

## 验证

- assembleDebug、testDebugUnitTest、lintRelease 成功：413 项测试，0 失败、0 错误；Lint 0 错误，423 条警告。
- 新增覆盖零模糊、参数缓存隔离/失效、移动坐标更新、壁纸投影等价性及 ItemInfo 重新绑定的测试。
- 使用实际生产着色器做 144 组优化前后离线对比，包含零/非零模糊、零/非零折射、透明度以及通用/浮雕/精细图案组合。最大通道差 2/255，最差场景的平均通道差约 0.000096/255。
- 安装包版本 3.0.2-debug1（3000004），签名与既有版本一致。

本次未安装到手机、未执行 Android GPU 探针，也未测量真机帧率或功耗。离线结果用于检查行为与画面等价性，不能证明真机耗电降低的幅度。本候选包未上传发布。
