# DreamGlass 2.0.1-debug8 — 按需更新的响应延迟优化候选

基于已发布的 debug7，仅调整更新调度，保留当前材质、GPU 模糊、场景隔离和原生回调保护。用户反馈该候选试用效果良好，现作为预发布版本提供；本轮发布沿用同一 APK，未重新构建或操作实体手机。

- 合并后台抓屏的两层限速。原先队列和抓屏入口分别记录时间，临界时可能让已经等完的任务再次被拒绝，错过一次更新。
- 通知出现、面板首次显示及流体云展开时，160 ms 内允许最短 33 ms 的更新间隔。展开事件可以唤醒正在等待空闲期限的后台任务。实际抓屏继续串行执行，不在主线程等待。
- 短窗口结束后恢复原有预算：变化模式最短 100 ms，静态背景退至 167 ms；连续像素变化和普通原生事件不能延长短窗口。低刷新率设置继续有效。
- GPU 材质准备共享两个初始额度，随后每 50 ms 恢复一个额度，移除前两项材质之间的固定空等；优先处理还没有准备好背景的材质，每种材质只保留最新待处理输入。
- 新通知清除上一场景像素时保留可复用的 GPU 渲染器，减少反复初始化。屏幕关闭、故障和原有生命周期清理仍可释放资源。
- 无可见使用者、锁屏/AOD 及静态模式的抓屏边界保持不变，不增加普通页面切换监控，不引入 CPU 模糊。

## 本地验证

- 343 项单元测试通过，包括展开时提前调度、加速窗口到期、连续事件不能持续加速，以及 GPU 额度不能因反复请求或长时间空闲而无限累积。
- Release lint：0 Error / Fatal，358 项已有 Warning。
- 隔离 Android 模拟器执行实际 GPU 工作线程，验证初始两种材质、最新背景替换、切换场景清除旧图、已发布图像所有权和隐藏后停止计算。
- 27 项原有玻璃与通知背景保护验证通过，包含旧崩溃条件、原生回退、坐标与透明度、AGSL 材质和重入保护。
- APK 版本与升级签名已校验。结果见 [验证记录](validation/2.0.1-debug8/audit.json)。

模拟器软件 GPU 的耗时仅用于记录本地验证环境，不代表 ColorOS 实体设备的延迟或功耗。尚未测量真机改善幅度，不宣称完全消除延迟。
