# DreamGlass 1.1.6 · For ColorOS 17

- 粒子飘散、锁屏玻璃及其他应用／组件玻璃集中到会员页；采用五元诚信付款，首次提醒仅有“我已支付，请继续”“暂不支付，退出”，本地记录诚信确认，不联网核验支付。
- 首页新增横幅，关于页加入微信赞赏码和保存原图。基础功能免费；会员部分难以维护功能的建议与反馈仅对实际付费用户开放。
- 新增可调深浅的灰色底层，默认关闭；修正全局压暗被内置预设覆盖及不同场景强度不一致，自动黑白选择考虑灰底。
- 音乐卡片在玻璃实际接管后跳过额外原生阴影／轮廓层；保留原生回退与播放控件布局。
- 兼容新增 17.3.12 桌面的 ma.p0 动画回调，保留原 ma.r0，按完整字段类型识别；同时兼顾新旧删除代理。通知倾斜调整枢轴和观察距离。
- 流体云收起使用黑底，展开保留玻璃。

当前提供本地和模拟器验证。音乐修正、流体云、新桌面行为与倾斜仍需真机验收；不宣称已经解决所有主题或系统变体，未测量新版本功耗和长期稳定性。独立音量窗继续保留原生材质。升级后需按自己的方式重新加载所选作用域。
