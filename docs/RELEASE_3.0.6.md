# DreamGlass 3.0.6 · For ColorOS 17

- 在「设置 → 息屏与壁纸」中，可预览相片与信封效果，拖动、双指捏合或拨动滑杆调整构图。两种样式分别保存构图与显示内容，支持日期、时间、电量和充电状态。已有 Root 授权时可读取锁屏壁纸。
- 相片经快门展开，信封翻盖后抽出信纸。亮屏过渡到锁屏壁纸，熄屏沿同一轨迹收起。
- 适配系统桌面 17.5.5 的上划删除和一键清空粒子入口。删除时机和锁定任务规则仍由系统控制。
- 修复桌面图标包中部分应用和普通文件夹预览漏换。在线库和自定义图标合并后的目录可超过 500 项。
- 通知中心和控制中心可选用锁屏壁纸作下拉背景。自助故障排查可对比组件 APK 的 SHA-256，提供 Root 读取入口并改善浅色模式可读性。

## 安装与验证

APK 沿用 3.0.5 签名，可覆盖安装。覆盖后，在 LSPosed 中核对需要的作用域，再重新加载系统桌面和 SystemUI。需要使用息屏动画时，请先在系统设置中开启息屏显示。

已核对 Launcher 17.5.5 和 SystemUI 17.99.02 的样本。息屏编辑和应用内过渡已在模拟器验证。ColorOS 真机上的息屏衔接和多任务粒子仍需验证。

发行包包含相同构建的源代码和依赖源码、许可证及 SHA-256 校验和。
