# DreamGlass 1.1.9-debug1 · 会员门控与组件适配候选

按用户要求，本轮不连接 ADB，不安装、不重启、不点按手机。此包供后续手动验收，未宣称截图里的全部实际玻璃效果已成功。

## 会员功能

应用与通知倾斜现在与通知／多任务粒子、锁屏、相册／侧边栏／负一屏／通知展开菜单及流体云展开玻璃归入会员。会员页面保持“我已支付，请继续”“暂不支付，退出”两个动作，不接入支付 SDK，不联网核验。每个版本名与版本号都需要重新确认；已支持过的用户无需重复付款。

未确认时，统一配置读写门面强制会员布尔值为 false。旧 true 值、默认 true、备份导入、伪造确认字段及延迟提交 editor 不能启用会员；导出不含确认标记。确认后不自动恢复开关，需自行选择开启。

Hook 的实际回调另行检查当前确认，清理已经开始的粒子、倾斜与玻璃挂载。模块启动／框架绑定清理无效确认；更新接收器最多等待框架通道 8 秒。两份存储分别提交，失败会返回错误，不伪称原子成功。已运行旧 APK 的 Hook 无法由新进程直接替换，更新后仍需重新加载作用域。

## 页面与移除项

首页压缩标题与底部导航，将基础材质、会员扩展和维护入口分组。计算器玻璃的开关、Hook、默认作用域、包查询、诊断入口与专用测试均撤除；共享透明背景工具保留为通用实现供相册使用。

删除 COS17 不支持的旧桌面弹簧／淡入参数、COS16 独立音量三项覆盖、旧 PressFeedback 清理按钮和收起胶囊玻璃死卡。独立音量保留原生处理，流体云收起保持黑底，展开玻璃保留。背景模糊只用 GPU，CPU 精度选项及生产 CPU 回退均移除；CPU 数学实现仅保留作离线参考测试。
