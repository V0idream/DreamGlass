# Preview2 Refine2：COS17 进度填充链修复（离线候测）

日期：2026-10-22。包名 `com.dreamglass.cos17`；版本 `0.1.1-COS17-Refine2`，versionCode `10007`。

## 已修正的代码问题

1. 目标 SystemUI 17.99.02 的 `QsSeekBarBlurManager.getSeekBarActiveDrawable` 实际签名为 `(View, Rect, float, float, boolean, boolean, float) -> Drawable`。初版只查找 `(View)`，无法挂载。现在优先精确匹配七参数，旧版一参数接口作为后备，不按名称或参数数量猜测其他重载。
2. 工厂返回的是 `AutoBlurDrawable` 包装层；实际 `drawBlurShader` 的接收对象经过 `ViewBlurProxy -> PlatformBlurDrawable -> posteffect BlurDrawable`。初版登记前者、查询后者，身份匹配失败。现在在绘制映射时传递填充层身份到实际对象，并重新解析进度层目标以处理系统材质重建；不把背景轨道登记成填充层。
3. 半透明填充沿用初版意图与 `0x66` 白色透明度，只在实际一次绘制内设置 shader/colorFilter，`finally` 恢复画笔。避免暂停玻璃后残留填充状态。
4. 应用诊断增加宿主实际加载版本、进度接口、进度对象、进度填充、按钮遮罩路径，走现有诊断回传，不依赖打开详细日志或 Shell Root。

这里的七参数接口属于**控制中心音量/亮度滑块**，不是按硬件音量键弹出的独立音量面板接口。
