# DreamGlass 3.0.4 · For ColorOS 17

- 适配 ColorOS OTA 中的系统桌面 17.5.5 与 SystemUI 17.99.02，更新桌面玻璃背景录制、最近任务清除按钮、应用开关和返回桌面的倾斜动画入口。
- 修复关闭的大文件夹仍显示原色图标的问题，覆盖普通预览图标和右下角堆叠缩略图。
- 兼容新版顶部通知横幅的滑动删除。系统接受本次删除后触发粒子动画。
- 本版同时包含图标包重启恢复、部分 ColorOS 16 桌面兼容、锁屏歌词场景背景、天气页面玻璃材质和按钮模糊范围更新。

版本号为 3.0.4（3000006）。签名沿用 3.0.3，可覆盖升级并保留配置。安装后在模块框架中按需重新加载桌面与 SystemUI 作用域。

构建、单元测试、Lint、签名与发布包校验详见 [验证记录](validation/3.0.4/README.md)。本版尚未在更新后的手机上验证实际显示效果。
