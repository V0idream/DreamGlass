# DreamGlass 1.1.7 · 原生启动动画回归修复

用户反馈窗口倾斜没有生效，并使应用原有启动动画消失。本版先停止有风险的窗口倾斜注入，优先让启动／退出动画由系统原生处理，不再将未通过真机验收的倾斜路径作为可启用功能提供。

- 移除原厂窗口矩阵写入、SurfaceControl apply／merge／close Hook、仿射矩阵回调、逐帧监听与延迟单位矩阵复位。
- 桌面入口不再安装原生 Zuyqa 参数强制或旧版窗口倾斜 Hook；所有窗口倾斜安装路径均转为不可用状态。纯数学函数只保留供 debug 研究，不写入实际桌面。
- 应用窗口倾斜开关显示“已暂停”，关闭且不可操作，强度／透视控件禁用。旧的开启配置不会重新激活注入，也不需要清除应用配置。
- 不改系统全局动画倍率，不改原生启动／退出进度；通知卡片倾斜是独立选项，其他材质、会员和组件设置保留。

**升级后必须重启桌面进程**，才能卸载旧版已加载的 Hook。仅安装新 APK 不会替换仍在运行的旧代码。无需 Shell Root，也无需为此重启 SystemUI。

154 项单元测试通过，Debug／Release 构建和 Lint 通过（0 Error、307 Warning）。编译后的正式类审计确认安全入口没有事务、矩阵、偏好读取或复位调度，原生／旧版倾斜安装器已不被桌面入口调用；正式包界面实测确认开关关闭且禁用。本轮尚无真机动画恢复的可见验收，**不宣称倾斜已经实现**。

APK 沿用升级签名，提供完整对应源码、许可和校验和。1.1.6 在备份与核验后转为草稿隐藏，源码标签保留。开源许可与诚信付款说明不变。
