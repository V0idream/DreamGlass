# Preview5：恢复控制中心玻璃层次

用户反馈 Preview4 控制中心按钮的玻璃感消失，并提供截图。截图仍显示背景采样与模糊，边缘反光和折射弱化明显；仅凭截图不能证明每个按钮的 Hook 与背景捕获都正确。

## 已确认的代码变化及处理

- Preview3 / Preview4 的柔光路径把原折射强度乘以 0.42，边缘高光进一步降低。这次恢复完整折射数值，柔光开关只控制边缘反光，不再削减折射。
- 光边从约 1.2–3 px 调整为 2–4 px，增强定向反射，并以很弱的羽化反光连接到表面。使用屏幕混合保留背景颜色，未恢复原来的宽白圈加法。
- 原 Preview4 用宽泛 volume_panel / volume_seekbar 等身份片段识别原生场景。这次限定为独立音量窗口的具体类或命名空间，控制中心的 qs_volume_* 资源 ID 不构成独立音量窗口证据。
- 平台包装对象优先解析其回调捕获的 PlatformBlurHelper.hostView，并核对实际 View 及父链。无法取得 View 时，仅接受回调字符串开头的已知运行类名，不扫描任意资源 ID 或标题。
- 移除 Preview4 新增的宽泛层名排除，恢复 Preview2 的层名处理顺序。独立音量面板仍通过实际宿主、内部 drawable 弱引用与局部绘制作用域保护。
- 新增 control_uniforms 阶段，记录控制中心实际成功下发的首次折射、高光与柔光参数；它证明参数调用完成，不替代最终像素验收。

## 边界

本次普通 ADB 查询无在线设备；按用户此前选择，仅交付 APK 由用户自行安装。没有自动安装、使用 Shell Root 或重启作用域。新版本视觉是否满足要求，需要安装并重启 SystemUI 后检查。
