# DreamGlass 1.1.3 调试验证

2026-10-30，实机调试包为 `1.1.3-debug8`，发布包为 `1.1.3`，包名 `com.dreamglass.cos17`，versionCode `1001003`。正式包采用同一生产代码并排除调试探针。

## 本轮实现

- 通知粒子只 Hook 具体方法，跳过抽象 snap 回调；单个入口失败不再中断其余入口安装。实际高度裁剪 GPU 快照，沿原生滑动当前位置和方向衔接，开始播放后隐藏原通知源，结束或取消时仅恢复自身持有的 alpha。
- 一键清除只在已确认的 COS17 完成回调、请求收起、面板仍展开且有该窗口的粒子时暂缓收起。沿用原生 callback，不保存或异步使用 Xposed Chain；默认速度约等待半秒，最长 900ms。普通单条删除、没有粒子、未知回调布局均保留原路径。
- 等待期间重复完成回调合并；手动收起或 detach 取消过期任务，关闭粒子立即释放原生收尾。通知真正移除与 post-collapse actions 继续由系统管理。
- 侧边栏接原生 GPU 背景纹理、矩阵及既有裁剪，复用统一预设；原生模糊半径跟随预设，不再对其重复滤波。保留已获用户认可的 8px 透明玻璃输出，不改变其光学参数。
- 锁屏只登记真正可见的数字、日期、组件和快捷按钮，排除预创建但不可见的主题对象、整屏容器、AOD及认证界面；识别主题包装类中的原生按钮祖先。
- 相机按钮使用单个组件合成层绘制 GPU 玻璃与原生前景图标，保留原生 LayerDrawable 对象和点击/启动状态；扩展启动形变交还原生。
- 数字保持原字形 alpha，GPU 根据实际字形边缘产生高光与折射，不替换字体。debug 包一次性导出单个实际数字的 raw/native/glass/combined GPU 对照；release 不包含该导出类和探针 Activity。

## 本地证据

- 120 项 JVM 回归，无失败，包含真实 COS17 参数顺序、抽象入口、主题包装类和清除完成 callback 布局校验。
- API33 / SwiftShader 专用模拟器 9 组通过：GPU 后台、F16/滤波、生命周期压力、粒子、锁屏、动态姿态、共享场景、相机原生图层合成、一键清除等待。
- 锁屏探针：自绘数字覆盖 96123 像素，玻璃相对恒等 RenderEffect 的 alpha 差 0，前景保留率 100%，6 个点击回调保留，关闭恢复像素差 0。
- 相机探针模拟不调用背景 Drawable.draw() 的原生灰色圆形分支，实际 GPU 输出替换该灰底，保留原生图标及图层对象；启动形变回退与关闭恢复通过。
- 等待探针：不提前执行、重复回调只执行一次、手动收起后无延迟误关、detach 无残留、关闭特效立即释放收尾。
- 渲染帧已在本地实际打开检查，不使用探针恢复原生后的截屏充当玻璃效果证据。`gpu-probes-debug8.json` 为合成场景记录。

## 设备验证边界

此前 debug3–debug6 的普通 ADB 记录证明：通知删除 GPU 路径已执行，锁屏可见数字/按钮已识别；用户认可启用后的侧边栏透明材质。

后续手机重新连接，已读取 debug7 的实际数字 GPU 对照，并经用户授权覆盖安装 debug8；SystemUI 由用户手动重启。普通 ADB 记录确认 debug8 入口、粒子 REQUEST/ACCEPT/COMMIT、768×145 硬件纹理和一键清除等待（747ms）在实际系统中执行。没有据此宣称全部动画观感已验收。

数字原生 raw 与 native 图一致，单独应用 glass/combined 时能看到壁纸折射及边缘；但实际锁屏截图仍显得偏平，右下角原生相机按钮仍呈灰色，并且没有实际合成绘制阶段。因此这两项明确保留为实验性已知限制。用户决定不再继续调试；不通过修改截图或仅以“已绑定”记录宣称修复。动态倾斜也没有本轮真机完成证明。

未测量功耗或长时间 SystemUI 稳定性，以上记录不构成相关保证。

不使用 Shell Root，不自动重启 SystemUI。每次手机覆盖安装仍须取得用户明确授权。私有设备截屏、实际数字图、厂商 APK 和原始设备日志不放入公开源码。
