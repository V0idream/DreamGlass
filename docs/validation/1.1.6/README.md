# DreamGlass 1.1.6 验证记录

154 项 JVM 单元测试通过，0 failure／error／skip；Debug／Release 构建与 Lint 通过，0 Error、309 Warning。升级签名保持一致，正式包 versionCode=1001006，不包含 debug 探针与历史参考着色器资产。

## 可读性与光学

6 组 GPU／生命周期夹具通过。两种光学曲线分别与历史参考进行 48 组比较，在关闭新增灰底与压暗的对照中最大 RGBA 通道差为 0。灰底深浅端点的实际 GPU 输出不同，圆角透明保留；相同压暗值在 polished 与普通材质的中心颜色一致。灰底在着色器内完成，没有新增位图处理或抓屏循环。自动黑白选择会将灰底与压暗纳入亮度近似和缓存键。

显式全局压暗优先于内置预设的弱压暗值，显式组件覆盖仍优先。原先 polished 材质额外乘 0.65 的衰减已移除；通知中心／控制中心与弹出通知采用相同强度语义。

## 界面与诚信确认

在隔离模拟器的正式 release 包中操作并截图：首次提示只有“我已支付，请继续”“暂不支付，退出”；退出确实离开应用，下次打开基础页面可用，会员入口仍要求诚信确认。点击确认仅写本地偏好，不执行支付或验证；随后可进入独立粒子设置页，锁屏／其他组件／流体云归组。首页横幅跳转关于页，关于页可进入会员说明。赞赏码展示与保存通过，新增相册文件 SHA-256 与项目所有者提供的 PNG 一致。

会员页明确显示基础功能免费及五元诚信付款；难维护扩展的建议与反馈仅对实际付费用户开放。锁屏在付款说明中标为实验性。灰底开关默认关闭、深浅默认 65%，单独滑条可见。界面截图是模拟器输出，赞赏码是项目所有者明确要求随软件提供的素材。

## 媒体、桌面与流体云

从给定 SystemUI 的原生媒体绘制中确认，背景之后另画 MultiLightDrawable 阴影／轮廓。仅在本模块玻璃实际绘制后跳过这一额外装饰，支持缓存 RenderNode；原生回退保留装饰。音乐几何仍保留上一版原生边界与裁剪处理，原生播放控件布局不变。

新桌面与旧桌面同为 17.3.12，R8 回调名由 ma.r0 变为 ma.p0，ma.r0 已被复用于另一用途；通过完整捕获字段类型选择正确回调，不只看版本名。旧入口保留，删除代理兼顾两组接口。详见 launcher-compat.json。原始 APK、反编译内容与 native 分析不包含在源码中。

通知倾斜保留原生进度，改用上边缘枢轴及与卡片尺寸匹配的观察距离，结束时恢复枢轴和原生属性。收起的 CapsuleView 使用黑色背景，展开卡片仍走独立玻璃路径；旧的小胶囊玻璃开关被隐藏。
