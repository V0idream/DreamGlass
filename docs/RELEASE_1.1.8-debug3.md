# DreamGlass 1.1.8-debug3 · COS17 适配候选

这是用于继续排查与验证的预发布版。构建、静态契约和合成 GPU 测试通过，尚未完成三个系统应用、通知菜单或窗口倾斜的真机视觉验收。

- **玻璃区域调试**：设置 → 日志与诊断 → 显示玻璃渲染框。青色边界标记实际执行共用 GPU 材质且最终可见的部分，随形状与裁剪变化。没有青框时还需结合诊断日志，边界可能被前景遮挡或后续裁剪。
- **计算器、相册、负一屏**：根据当前提取的 17.2.16／17.10.41／17.14.60 APK 增加针对性入口；材质挂载后才局部抑制原生底色和装饰。计算器在原生父容器挂载一次，避免父子重复滤波。文字、图标与输入保留原生路径。
- **通知菜单**：补齐 Drawable 实际边界、局部偏移、padding、alpha 与状态；缺少背景源或绘制失败时回退原背景，避免将空绘制误报为成功。截图中的矩形异常仍需真机对照确认。
- **窗口倾斜兼容模式**：将倾转合进当前原生仿射矩阵，保留缩放与中心路径，不再使用有风险的独立 4×4 事务或定时复位。这是三维旋转的平行投影，**没有完整近大远小透视**；新安装默认关闭，实际可见效果尚待验证。

175 项单元测试通过；Debug／Release 构建通过，Lint 0 Error／0 Fatal。渲染框六组 GPU 回读、正常光学 48 组对照和菜单边界／透明度／回退 GPU 检查通过。这些合成测试不能替代 OEM 宿主上的可见验收。

本轮已通过普通 ADB 覆盖安装 debug3，并核对安装版本。**没有自动重启进程或继续点按测试。** 新 Hook 仍需在用户选择的时间手动重新加载对应作用域：通知菜单为 SystemUI，窗口倾斜为桌面，其他适配为各自应用。仅安装 APK 不会替换已运行进程中的旧 Hook。

1.1.7 保留为最新正式版，本候选不自动取代正式版本。旧版备份、隐藏状态和源码标签不变。
