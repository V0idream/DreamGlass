# DreamGlass 1.1.9-debug5 · 清理按钮与保存面板候选

针对用户在 debug4 中看到的清理按钮只剩文字、相册保存大面板仍偏灰的问题继续修正。此为本地候选，未完成 ColorOS 真机验收。

- 清理按钮改在自身 `onDraw` 的文字之前直接绘制。保留原生背景与实时输入 shader，不再把原生 RenderNode 录制成功当作材质可见；不修改其 Paint、点击、任务删除或动画回调。
- 原生背景对象不存在、模糊关闭、原生 Paint 透明度为零或输入全透明时，仍有轻量的圆角底色与细边缘。只在本次 Canvas 确实画出可见底层后，才跳过原生重复底色；原生隔离动画禁止绘制时仍服从其状态。
- 有原生 GPU 输入时使用共用玻璃预设直接取样；无输入时明确退回可见底色，不用截图、壁纸文件或 CPU 模糊冒充实时玻璃。不额外安排持续刷新帧。
- 相册保存弹窗补上 Dialog 的显式所属 Activity 关联，并将两个独立窗口的矩阵锚定到实际屏幕原点，修正主题上下文与窗口偏移引起的缺源或错位。大面板已有灰色 overlay 的精确租用仍保留。

截图中保存面板背后是黑色编辑画布，而照片只在页面顶部。正确玻璃不会把不在背后的照片复制到面板里；纯黑来源本身缺少可折射的纹理。本版修正来源关联与坐标，没有人为搬移照片或替换编辑画布。

## 验证与限制

265 项 JVM 测试、Debug／Release 构建通过，Lint 0 Error／Fatal、352 Warning。隔离 Android 模拟器的生产绘制核心通过 11 项 GPU 断言，包括无输入／全透明输入下胶囊仍可见、实时输入变化、轮廓外透明及原生 Paint 不变。详见 [验证记录](validation/1.1.9-debug5/README.md)。

模拟器不具备 ColorOS 的原生按钮和相册组件；不将上述核心检查当作 OEM Hook 命中或实体效果验收。本轮未连接、安装或操作实体手机，尚无该版本真机结论。

覆盖安装保留配置；目标进程需要重新加载才会运行新代码。会员确认行为仍按之前约定延后调整，无新增依赖。项目整体遵循 GPLv3，原项目及 Apache-2.0 着色算法来源见 LICENSE、NOTICE、THIRD-PARTY-NOTICES.md、MODIFICATIONS.md；同时提供对应完整源码。
