# Preview2 Refine4：控制中心轮廓与材质精修

交付日期：2026-10-23。版本 `0.1.1-COS17-Refine4` / versionCode `10009`，包名 `com.dreamglass.cos17`。

用户已确认 Refine3 的玻璃效果能够生效。此次以该版本提交 `7d2208598be20ab8690894b9facdf83b9a74dec1` 为基线，针对截图中的三个问题及追加的独立音量面板故障修改，保留已经生效的生命周期、内容录制和背景采样入口。

## 修改

1. **亮度/音量滑杆方底**：原模块在进度层绘制时暂时移除 shader 并画半透明填充，绕过 shader 内的圆角；所给 ROM 的 `drawActiveMixColorTrack` 则只执行矩形进度裁剪。本版在该方法外层再裁剪当前滑杆的完整轮廓，读取 COUI 父类中的 `mClipProgressRect`、`mCurProgressRadius`、`mBackgroundRoundCornerWeight`，通过 ROM 自身的 `OplusPathAdapterCompatUtils` 构造平滑圆角。不可用时采用相同实时半径的圆角路径；缺少有效几何时保持原生绘制。原生进度高度/拖动/动画不变，Canvas 在 finally 中恢复。此项裁剪只作用于控制中心滑杆；独立音量窗口由下面的原生保护处理。
2. **三个横向按钮的内圈**：登记 `OplusQSIconView.iconBgView` 的独立背景 Drawable，仅当它实际属于 `OplusQSResizeableTileViewTwoXOne` 且玻璃开启时跳过该背景的绘制。不改 View 可见性、图标、布局、颜色或状态，关闭玻璃时自然恢复原生绘制。普通 1×1 圆形按钮和顶部设置/账号图标不受此规则影响。
3. **减轻塑料感**：在现有 AGSL 内增加控制中心/通知场景的精修分支。宽高光带改为按尺寸约束的窄反射与柔和衰减；高光按颜色到当前 alpha 的剩余空间叠加，避免亮部过曝；光与玻璃使用同一预乘 alpha，避免圆角外 RGB 有值而 alpha 为零的硬亮边。保留原有折射、色散、采样和形状算法。
4. **通透度**：精修分支内的有效模糊为原请求值的 60%，玻璃内部压暗系数为原请求值的 65%，减少背景细节被模糊和染黑覆盖。没有重置、导入或写入用户参数/预设。这是渲染方式调整，参数存储不变；原始模糊值为零时仍为零。Launcher、锁屏时钟及独立音量面板不选择此分支；应用内材质预览与控制中心采用相同分支。
5. **独立音量面板**：此前 VolumeMaskGuard 只保留外层 blurMaskColor，未保护内部 posteffect 对象；场景注册又依赖共享层名，独立面板仍可能走通用玻璃接管。本版在 ViewBlurProxy 提供材质时按真实 View/父级识别音量窗口，将包装层和真实内部对象一起登记为原生材质；在 AutoBlur 映射和包装绘制处补充登记。内容录制和 shader 替换入口均提前放行这些对象，清除可能残留的模块 shader，不把它们登记为控制中心玻璃区域。保留系统的音量专用抓屏、冻结/更新、遮罩及动画。只缓存已确认的音量归属，避免第一次查询发生在 View 挂接前而永久缓存错误的否定结果。控制中心的音量滑杆继续使用自己的修复路径。
6. **诊断**：增加滑杆轮廓接口/实际裁剪、横向图标底层接口/实际跳过，以及独立音量归属接口/实际原生保护记录；记录表示路径被执行，不等于像素验收。

## 参考边界

只读参考“液态玻璃适配 (2)”分支、现有接口核验资料及用户导出的 Elbow 配置，了解其透明色层、低压暗和独立图标底层控制的思路。新裁剪、图标绘制路由和精修着色分支均在本项目独立实现，没有复制 Elbow 的实现、shader 或原生库，也没有向本模块导入它的配置。项目既有开源代码的来源和授权继续保留，见 THIRD-PARTY-NOTICES.md。

预乘透明度遵循 [Skia Runtime Effects 文档](https://skia.org/docs/user/sksl/)；Canvas 裁剪在保存/恢复范围内执行，见 [Android Canvas](https://developer.android.com/reference/android/graphics/Canvas)。实际厂商接口以所给 ROM DEX 为准。

## 验收边界

本修订未安装、未连接手机、未重启或切换任何作用域，未改变手机上的参数。上面的渲染图全部是程序生成的离线夹具，桌面 Skia 检查不能替代 Android GPU、Hook 实际调用及真机外观验收。Refine3 的用户通过结论不自动延伸到 Refine4。

复测时使用同签名 APK 覆盖安装，保留现有配置，按原方式手动加载。重点查看滑杆底角及 0/满进度、三个横向按钮的图标、其他圆形按钮是否保留外形，以及深浅背景下的边缘和通知卡片。独立音量窗口需要另测首次弹出、反复按键、拖动、展开多流滑杆、静音/蓝牙与收起动画，确认没有闪白、方块、内容错位或背景停留。无需为了本次修订重新导入 Elbow 配置。
