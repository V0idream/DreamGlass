# DreamGlass 1.1.9-debug2 · 原生玻璃与批量清理修正候选

保留相册保存菜单、按钮、负一屏和桌面卡片的玻璃功能。本轮按用户要求不连接 ADB，不安装、不重启、不操作设备；厂商合成器的最终显示及相册保存流程仍需真机验收。

## 相册保存菜单

静态分析确认 COUIButton.setBackground 会把参数写入现有 COUIStateEffectDrawable 的第 0 层。旧方式若包装整个背景，会形成“状态容器 → 透明包装 → 原状态容器”的循环，轮廓、padding 等查询可能递归。本版不再通过该转发 setter 包装整个容器，只在验证后的原生图层索引 0 租用底色，保留状态／触摸层、文字、加载状态与原生保存逻辑。图层图必须无环且不能指回容器，未知结构保留原生。关闭时只还原仍由本模块持有的图层，避免覆盖主题的新背景。

这是可由实际组件源码确认的危险路径及针对性修正；没有设备崩溃栈，不能宣称它已被证实为此次闪退的唯一原因。未通过移除保存菜单玻璃功能规避问题。

## 相册位置与遗漏入口

- 主页导航使用原生绘制矩形的宽高转换至子控件局部坐标，保留 RTL 锚点和原生弹簧尺寸；不重复叠加父坐标、滚动或原生缩放。
- 原生控件的玻璃蒙版固定在控件边界。共用 shader 的 parallax 本来会连蒙版一起移动，使固定按钮出现错位和矩形切边；只在 AppGlassEffect 适配层归零，SystemUI／控制中心的光学方案与参数保留。
- 对精确匹配的相册原生宿主增加可逆 RenderNode 圆角裁剪，约束背景滤镜外扩；不移动图标／文字。
- 单图页底部独立接入 COUIBottomFloatingToolbarMenuView 的实际背景 bounds；顶部更多按钮接入 PhotoMenuMaterialEffectController 使用的语义工厂内部材质宿主，包含 FrameLayout。保留照片、缩略图、前景与输入，不把整个顶栏／底栏加框。
- 原生材质装饰只在对应宿主已挂载替代玻璃时跳过；不把原生对象字段清空，也不跳过整个 onDraw。

## 负一屏与小布建议

搜索、AI、添加三个按钮使用原生 Path 同时裁剪自身及其精确配对的 *_blur 兄弟背景层，避免矩形底色透出；排除头像，保留 ImageView.src 与文字。

用户已纠正桌面四图标卡片为“小布建议”。本版按 SuggestCompactBgView、TitleCardView 和 SuggestNoPaddingViewWrapper 的互相身份、卡片类型 82/83、原生圆角提供器挂载其独立背景，保留四个图标兄弟节点。此前已有的大文件夹适配仍单独保留，不能作为小布建议已适配的证据。createBlurBackground 同时支持新旧参数顺序。

## 多任务全部清除粒子

原单卡入口保留。COS17 堆叠清空改走 RecentsViewAnimUtil 的逐卡动画辅助函数，此调用发生在原生锁定／快速启动排除之后；按精确类和方法签名新增 Hook，去优化真实调用者，随原生 PendingAnimation 确认开始／取消。

GPU 快照的 180 ms 时限从动画接受时计算，不再把原生构建等待误当 GPU 过期。已记录的批量卡片可在原生先分离 View 后于原 root 坐标继续播放；不压制分离或重绑定后的 View。保持最多两张可见卡片并行、单 GPU 快照工作线程、尺寸／队列／生命周期上限，熄屏、省电、关闭或撤销会员确认停止播放。没有改动原生任务删除回调、锁定过滤或系统返回桌面流程。
