# DreamGlass 1.0.5 — 修改声明

修改者：DreamGlass contributors；发布维护者：V0idream。相关修改日期：2026-10-22 至 2026-10-25。

本作品基于 AYwlilwYA / ColorOS16-LiquidGlass `aa96e1aeb98f4e3777f4bced265a1b86bf3e10cd`，整体继续按 GNU GPLv3 分发。原作者及第三方组件的版权与许可均保留，详见 LICENSE、NOTICE 和 THIRD-PARTY-NOTICES.md。

## 修改范围

- 1.0.5（2026-10-25）：新增中性色按钮图标自动黑白适配、独立开关、公共 tint 参数观察及 Android 绘制/恢复测试；不改既有玻璃算法。

- 1.0.4（2026-10-25）：显式线性纹理采样、改善共享背景尺寸和模糊精度；增加仅在调试包中的 Android GPU 回归及画质测试。

- 1.0.3（2026-10-24）：增加按钮背景跟随系统模糊开关、后台共用预模糊图及对应测试；默认关闭，未更改现有 AGSL 光学算法。

- 1.0.3（2026-10-24）：增加按钮背景跟随系统模糊开关、后台共用预模糊图及对应测试；默认关闭，未更改现有 AGSL 光学算法。

- 1.0.2（2026-10-24）：将按钮透明度重做为背景模糊，移除材质 alpha 缩放，旧配置不再读取；补充模糊解析、渲染与应用预览验证。

- 1.0.1：压缩参数页布局，增加全局按钮材质透明度，按局部背景选择文字黑白并补充测试。

- 独立品牌 DreamGlass、三层图形标记、工作台、材质工作室、运行状态及分组参数页。
- 替换旧作者社交/收款入口；增加离线来源说明、GPL/Apache 全文及精确依赖清单。
- 独立应用 ID、框架配置与应用生命周期；适配 COS17 的实际截图、桌面和绘制接口。
- 通知/控制中心绘制入口、进度轮廓、图标底层、材质高光及独立音量场景保护。
- 诊断回传、配置备份、隐藏桌面入口与经确认的应用内进程重启。
- 两份 LibXposed AAR 仅修改 minCompileSdk 元数据 37→36，并增加日期/修改注释，其余条目不改。
- 部分着色算法来自 Copyright 2025 Kyant / AndroidLiquidGlass 的 Apache-2.0 代码，相关文件保留原许可头并标注修改。
