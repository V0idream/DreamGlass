# DreamGlass

**For ColorOS 17** · 版本 **1.1.6**

可调整的系统玻璃材质应用。基础功能完全免费；粒子飘散、锁屏玻璃，以及其他应用／组件玻璃集中到“会员功能”，采用五元诚信付款与本地确认，不联网核验支付。首次提醒只提供“我已支付，请继续”和“暂不支付，退出”。退出不会关闭已启用的系统效果；下次仍可打开基础功能，会员入口继续要求诚信确认。

## 这个版本

- 首页增加入口横幅，关于页展示开发者提供的微信赞赏码并支持保存原图。声明会员部分难以维护功能的建议与反馈仅对实际付费用户开放。
- 新增默认关闭的“灰色可读性底层”和深浅滑条，作用于共享玻璃材质，保留折射与图标。自动黑白对比选择考虑灰底与压暗。
- 修正全局玻璃压暗被内置预设小值覆盖的问题；统一通知中心、控制中心与弹出通知的压暗强度，显式组件覆盖仍保留。
- 音乐卡片新增原生阴影／轮廓层去重，仅在本模块玻璃实际接管时跳过额外媒体装饰，包含 RenderNode 缓存绘制路径；原生回退不删除装饰。
- 新增另一份 17.3.12 桌面的标准动画回调匹配，同时保留旧版入口；调整通知倾斜的枢轴与观察距离，结束时恢复原生属性。**窗口与通知倾斜仍为实验性，真机可见效果尚未确认。**
- 流体云收起胶囊使用黑底；展开卡片保留独立玻璃路径，取消与此冲突的小胶囊玻璃开关。

本版完成构建、单元、GPU 与隔离模拟器界面验证，详情见 [1.1.6 验证](docs/validation/1.1.6/README.md)。新桌面为静态契约适配，音乐、流体云与倾斜仍需实际 ROM 重新加载后验收。未声称完成新版本功耗或长期稳定性测量。

诚信付款是应用的支持方式，不修改本项目及第三方代码所附的开源许可与对应源码提供方式。

## 支持范围

Android 13+；目标 ColorOS 17 样本为 SystemUI 17.99.02、Launcher 17.3.12。模块功能需要支持 LibXposed API 102 的兼容框架与对应作用域。部分动画仍受 ROM 限制，见 COMPATIBILITY.md。

安装后从应用保存配置，在框架中选择作用域，再按自己的方式重新加载目标进程。软件不会自动请求 Root、重启进程、修改系统分区或清除用户数据。隐藏桌面图标后，可通过 LSPosed 的模块设置入口打开应用。
