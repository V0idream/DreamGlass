# DreamGlass

**For ColorOS 17** · 版本 **1.0.7**

可调整的系统玻璃材质应用。提供独立工作台、材质工作室、运行状态、分组参数页与离线开源许可页。显示名称是 DreamGlass；For ColorOS 17 只表示支持范围。

## 这个版本

- 1.0.7：修正 1.0.6 把截图来源判断写反、实际控制中心未使用高精度预模糊的问题。首次构建与每帧刷新共用背景绑定；计算等待阶段避免使用大间距稀疏网格。保留现有边缘厚度。

- 1.0.6：独立材质与共享按钮背景都采用后台密集预模糊，五轮可分离高斯近似、双精度累加、浮点中间值及 RGBA_F16 输出；避免在按钮着色阶段重复稀疏网格采样。保留采样密度，最高约 100 万像素 / 2048px 长边。
- 边缘保留细高光，增加方向性内侧亮肩和暗部，形成柔和厚度；不扩大轮廓、不改变中央通透度。此改动为 DreamGlass 自行实现。

- 「文字与可读性」新增「按钮图标自动反色」，默认关闭。控制中心中性色图标按各自按钮背景选择黑白，保留彩色状态、原透明度及头像；与文字开关独立。
- 修复背景放大后的像素方块：两条 BitmapShader 输入显式使用线性插值，保留更多背景细节，模糊过程采用浮点精度并连续处理小半径。
- 「采样与性能 → 系统控制中心模糊」新增「同时应用到按钮背景」，默认关闭。开启后按钮背景跟随同一系统模糊力度，关闭后恢复独立模糊设置。
- 压缩参数页标题与预览，留出更大的参数滚动区。
- 控制中心新增「按钮背景模糊」0–64 px：低值保留背景细节，高值更柔和；按钮材质、图标与文字不随滑杆淡出。
- 修正 1.0.1 对透明度需求的误解，移除材质 alpha 缩放。旧透明度键不再读取；未设置新选项时继承原材质模糊。
- 自动反色按各按钮/卡片区域的背景决定黑白，优先于旧版强制白字。

- 统一的深色青绿色界面、原创三层图形标记和四页导航。
- 将继承的参数长列表重新组织为功能卡片，保留现有参数和配置格式。
- 替换旧项目的联系人、赞助和自动升级入口；源码、版权和许可统一放在关于页。
- 保留 Refine3 已由用户确认生效的绘制接入，以及 Refine4 的轮廓、图标底层、材质与音量保护修补。
- 版本号与运行记录统一从构建配置读取，安装包 ID 不变，支持同签名覆盖升级。

## 支持范围

Android 13+；目标 ColorOS 17 样本为 SystemUI 17.99.02、Launcher 17.3.12。模块功能需要支持 LibXposed API 102 的兼容框架与对应作用域。部分动画仍受 ROM 限制，见 COMPATIBILITY.md。

安装后从应用保存配置，在框架中选择作用域，再按自己的方式重新加载目标进程。软件不会自动请求 Root、重启进程、修改系统分区或清除用户数据。隐藏桌面图标后，可通过 LSPosed 的模块设置入口打开应用。
